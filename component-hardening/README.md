# Component Hardening SSOT

权威说明：[`docs/COMPONENT_HARDENING.md`](../docs/COMPONENT_HARDENING.md)

本目录由 `npm run hardening:generate` 等脚本维护：

- `inventory/` — 唯一组件库存、Family、Batches、maturity v4、gap
- `contracts/` — 每组件 API 契约
- `gates/` — Gate Profile 与 verify 结果
- `dashboard/` — 汇总指标
- `reports/` — API audit / Family evidence / SSR / Visual / Stable / Close

勿在仓库根目录再堆 V1/V2/V3 计划草稿。
