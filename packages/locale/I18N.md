# 多语言规范 I18N（锁定）

> 实现：`packages/locale/` · `LocaleService` · `useLocale()` · `html[data-locale]`  
> Agent 记忆：`.cursor/rules/vue3-amg-webui-i18n.mdc`

---

## 1. 目标

按钮文字、页面标题、提示信息、错误信息、表单校验与业务文案 **一律走 key**，禁止在组件/页面/**example 调试壳**硬编码用户可见字符串（品牌专有名词 `AMG-WebUI` 除外；其余 demo 文案也必须有 key）。

硬编码（文案 / hex / 随意 px·rem）视为 **bug**。Cursor：`vue3-amg-webui-no-hardcode.mdc`（alwaysApply）。

---

## 2. 目录

```
packages/locale/
├── I18N.md
├── index.ts
├── keys.ts
├── messages.ts             # LocaleCode + locales + LOCALE_META
├── zh-CN/                  # 简体中文
├── zh-TW/                  # 繁體中文
├── en-US/                  # English
├── ja-JP/                  # 日本語
├── ko-KR/                  # 한국어（韩国）
├── ko-KP/                  # 조선어（朝鲜）
└── ru-RU/                  # Русский
```

新增语言：复制任一现有目录 → `messages.ts` 注册 → 补齐**全部 key**（缺 key 视为 bug）。

| 代码 | 语言 |
|------|------|
| `zh-CN` | 简体中文（默认） |
| `zh-TW` | 繁體中文 |
| `en-US` | English |
| `ja-JP` | 日本語 |
| `ko-KR` | 한국어 |
| `ko-KP` | 조선어 |
| `ru-RU` | Русский |

切换：顶栏下拉、`LocaleService.setLocale(code)`、URL `?lang=ja-JP`。  
`toggle()` 按 `LOCALE_CODES` 顺序循环全部语言。

## 3. Key 命名

```
{domain}.{entity}.{descriptor}

button.save
page.theme.title
tip.saved
error.network
biz.login.title
auth.login.passwordRequired
```

| 域前缀 | 用途 |
|--------|------|
| `common.*` | 通用词：是/否/加载中/未知 |
| `button.*` | 按钮文案 |
| `page.*` | 页面标题 / 导语 / eyebrow |
| `tip.*` | 成功/信息类轻提示（Toast info/success） |
| `error.*` | 错误 / 失败 / 校验失败 |
| `biz.*` | 五大业务模块（login/users/orders/content/settings） |
| `auth.*` | 登录注册流程 |
| `nav.*` | 侧栏 / 面包屑（与路由 meta.title 可共用 key） |

**规则**

- 全小写 · 点分层 · 英文词干  
- 同一语义全局一个 key（`button.cancel` 不要再拆 `biz.cancel`）  
- 插值：`error.minLength` → `最少 {min} 个字符`，用 `t(key, { min: 6 })`

## 4. 使用方式

```ts
import { useLocale } from '@amg-webui/hooks'
import { LocaleKeys } from '@amg-webui/locale'

const { t } = useLocale()

t(LocaleKeys.button.save)           // 保存
t(LocaleKeys.error.minLength, { min: 6 })
```

模板：

```vue
<Button>{{ t('button.save') }}</Button>
<h1>{{ t('page.theme.title') }}</h1>
```

Toast：

```ts
ToastService.success({ summary: t('tip.saved'), detail: t('tip.changesLive') })
ToastService.error({ summary: t('error.generic'), detail: t('error.network') })
```

路由 `meta.titleKey: 'page.theme.title'`，壳层 `t(route.meta.titleKey)` 设置顶栏与 `document.title`（优先于写死中文 title）。

## 5. 覆盖范围（必须）

| 类型 | Key 前缀 | 示例 |
|------|----------|------|
| 按钮 | `button.*` | save / cancel / delete / confirm / continue / refresh / create |
| 页面标题 | `page.*.title` | page.users.title |
| 提示 | `tip.*` | tip.saved / tip.copied |
| 错误 | `error.*` | error.network / error.unauthorized / error.validation |
| 表单校验 | `error.validation.*` 或 `auth.*.Invalid` | passwordRequired |
| 业务模块 | `biz.<module>.*` | biz.orders.empty |

## 6. LocaleService

- `LocaleService.init()`：读 `localStorage` + URL `?lang=zh-TW` 等  
- `setLocale(LocaleCode)` → `html[data-locale]` + `lang`/`dir` + 持久化  
- 缺省：`zh-CN`  
- 切换后通知订阅者；与 Theme 独立  
- `LOCALE_META`：原生显示名（简体中文 / 繁體中文 / English / 日本語 / 한국어 / 조선어 / Русский）  

存储键：`amg-webui-locale-v1`。

## 7. Do / Don't

**Do**

- 新文案先加 `keys.ts` + **全部**语言包同步  
- Play 与 business 组件用 `t()`  
- 错误与提示用 tip/error，不用 button key  

**Don't**

- `<Button>保存</Button>` 硬编码  
- 在 SCSS 写文案  
- 中英文混在同一 locale 文件的无序大对象而不分域文件  
- key 用中文或驼峰（`按钮保存` / `btnSave`）

## 9. 文案长度（中英膨胀 · 禁止误伤 `…`）

中文常 2 字即可（保存 / 取消），英文往往多词（Save / Sign out / Continue editing）。按中文宽度固定布局，英文会被 `text-overflow: ellipsis` 截成 `…`。

### 原则

| 文案类型 | 策略 |
|----------|------|
| 按钮 / 导航 / Tab / 页面标题 / 退出等 **UI 文案** | **优先撑开或换行**；最多 2 行 clamp，不要单行强制 `…` |
| 用户名、ID、长路径等 **动态数据** | 允许 ellipsis，**必须**配 `:title` / tooltip |
| 表格表头 | 允许换行；单元格数据可 nowrap + ellipsis |

### 实现入口

- `packages/theme/styles/i18n-layout.scss`（已 `@import` 进主题）
- `html[data-locale='en-US'|'ru-RU']` 加宽侧栏/Tab；`ja-JP` / `ko-*` 轻度加宽  
- 工具类：`.i18n-label` / `.i18n-btn-label`（可 wrap）· `.i18n-truncate`（故意截断）· `.i18n-clamp-2`
- Button：`overflow: visible`，宽度随文案；极窄处用 `.p-button-wrap`

### Do / Don't（长度）

**Do**

- 英文环境下依赖 `data-locale` 变量，勿为中文硬编码 `max-width: 4em` 装按钮
- 英文文案尽量短（Sign out 优于 Exit this session），与设计对齐

**Don't**

- 对按钮文案写死 `overflow: hidden` + `white-space: nowrap` + 固定宽度
- 用缩小字号「塞进」中文框代替留白/换行

1. `keys.ts` 增加常量

5. 必要时更新本文与 Cursor rule
